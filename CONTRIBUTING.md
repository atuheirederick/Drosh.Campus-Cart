# Contributing

Thanks for your interest in Drosh Campus-Cart UG!

1. Fork the repository and create a branch: `git checkout -b feature/my-change`
2. Edit `index.html` (no build step needed — open it in a browser to test).
3. Test as both a customer and an admin, in light and dark mode, on a narrow (mobile) screen.
4. Commit with a clear message: `git commit -m "Add: short description"`
5. Push and open a Pull Request describing what changed and why.

Please never commit real credentials, PINs, OTPs or payment details.
